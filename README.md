# 解压台 · 多通道项目解压与任务中心

### ✨ 项目简介

**解压台**是一款基于 **Tauri 2 + Rust + Vue 3 + Pinia** 的桌面批量解压应用：把"解压压缩包"升级成"项目交付流水线"。每个通道拥有独立的文件队列、输出目录、层级规则、重名策略、密码与项目辅助工具；全局调度器负责并发、优先级、暂停、恢复、预检查与任务历史。它还能与 **Claude Code** 联动——解压完成后自动在输出目录打开 Claude 继续干活。当前版本 **0.8.4**，仓库内提供免安装的 `JieYaTai.exe`。

### 🎨 主要特点

- 📥 **多通道队列**：每条通道独立的队列、输出目录、层级/重名策略、分类与密码
- 💌 **关键词收件**：按关键词扫描目录（可递归、可排除 alpha/beta/rc 预发布、优先选最高版本号）自动进货
- 🤖 **Claude 联动**：解压完成后自动运行 Claude（生成/复用项目 DAT，CLI 自动探测 PATH / npm 全局 / 官方包），同目录 8 秒防重复启动
- 🖼️ **自定义背景**：铺满/焦点/缩放/亮度/模糊/暗角/遮罩精调，四套快速效果
- ⏱️ **自动化**：导入后自动开始、总开关新通道默认值、预设与配置持久化
- 🧭 **任务中心**：并发调度、优先级、暂停恢复、预检查、任务历史

### 📦 包含模块

1. **通道系统**—— 队列、规则、密码、分类、预设与自动开始
2. **关键词收件**—— 扫描目录 + 关键词 + 版本识别（`2.10.0` 高于 `2.9.9`）
3. **Claude 集成**—— DAT 生成/打开、CLI 状态检测卡、固定工作目录
4. **全局调度器**—— 并发、优先级、暂停/恢复、预检查与历史
5. **外观中心**—— 自定义背景、通道穿透与不透明度、主题
6. **文档**（`docs/`）—— 每个版本的发布说明、实现清单与测试报告

### 🛠️ 如何使用

1. **免安装运行**：直接下载仓库根目录的 `JieYaTai.exe`
2. **从源码构建**：

   ```bash
   npm install
   npm run tauri dev      # 开发
   npm run tauri build    # 打包
   ```

3. **基础流程**：新建通道 → 设输出目录与规则 → 拖入压缩包（或配置关键词收件）→ 自动解压到目标结构
4. **Claude 联动**：通道设置里开启「解压完成后自动运行 Claude」，确保本机已安装 Claude Code（未装时会提示官方 npm 安装命令）
